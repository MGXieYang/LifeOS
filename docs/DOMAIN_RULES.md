# 业务计算规则
## 工作日
年度 JSON 的 WORKDAY/HOLIDAY 优先；未覆盖日期按周一至周五。未收录年度首页、心愿和统计明确显示估算提醒。2025、2026 为已核实日历，不虚构 2027。
## 工时
上班、午休开始、午休结束、下班四个时间点均可自定义并本地保存。必须满足 上班 < 午休开始 < 午休结束 < 下班；暂不支持跨夜。每日秒数为上午与下午两段秒数之和。默认 30600 秒。两段各自截断到 [0, 段总时长] 后求和；非工作日为 0。
状态分为 BEFORE_WORK、WORKING、LUNCH_BREAK、WORKING_AFTERNOON、AFTER_WORK、HOLIDAY；边界左闭右开。计时粒度为整秒，250ms 刷新只读系统时间。
## 收入
当月总秒数 = 法定工作日数 × 每日有效秒数。秒薪 = 月薪 / 总秒数，DECIMAL128 精度。
今日收入 = 月薪 × 今日秒数 / 当月总秒数；本月收入 = 月薪 ×（此前工作日数 × 每日秒数 + 今日秒数）/ 当月总秒数。禁止先舍入日薪再相加，月末完整工作量必须恰好得到月薪。UI HALF_UP 保留两位，Float 仅可用于绘制进度。
修改月薪或任一上下班、午休时间后立即重算全月，不需要重启 App，不保存历史工资、历史工时或实时累计金额。零工作日月份返回零收入与零进度，心愿换算提示无法计算。
今日进度 = 今日秒数 / 每日秒数；月进度 = 本月累计秒数 / 月总秒数。完成工作日只包含已经结束的工作日。
## 倒计时
上班前计至上班，午休计至午休结束，工作中计至下班，其他状态为零；下班倒计时含未来午休的自然时间。
发薪日取配置日与月末较小者。当天全天显示“今天发工资”，倒计时为零，不假定实际到账；次日起计算下月发薪日 00:00。不按节假日提前/延后。
## 心愿
价格允许 0，不允许负数；所需工作秒 = 价格 / 秒薪。分钟、小时除以 60/3600，日除以个人每日秒数，月除以当前月总秒数。工资修改后自动重算。排序从新到旧/价格升序/时长升序（当前统一费率下后二者顺序相同）。
## 退休
见 RETIREMENT.md。退休人员类别必须显式选择；出生日期可跳过但不能在未来。剩余工作日采用已收录日历和未来普通周，始终标注预计。
## 时间与生命周期
Calculator 接受 Clock/LocalDateTime。前台订阅启动刷新，后台无订阅停止刷新；每次刷新读取当前系统时区。跨日、改时区、系统改时均重算，恢复前台立即取时。

## 联网例外
2026-09-07 用户批准法定工作日允许联网；默认计算继续用缓存。网络数据验证成功后立即重算当前月份，用户数据不上传。每月发薪日 1～31 自定义是必备要求。
