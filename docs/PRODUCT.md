# 产品范围（V2.0 当前基线）
V2 与 V1 冲突时以 V2 为准，V1 只用于历史追溯。
主导航为当下、天平、时间、决策；设置及工作收入从当下进入。产品回答：我现在处于什么状态、一个选择消耗多少生命、我的时间余额如何、我为什么做过这些决定。
工作收入能力继续保留，并成为 Life OS 的基础换算引擎。
V1 包含首次引导、首页、心愿、统计、设置。用户输入税后月薪，可分别自定义上班、午休开始、午休结束、下班时间及发薪日，可选出生日期与退休类别。四个时间点可在首次引导修改，也可在设置页随时调整。
首页呈现今日金额、工作状态、工作进度、下班或午休倒计时、本月金额、发薪日、退休和最近心愿。
心愿支持增删改、实现状态与创建时间/价格/工作时长排序。统计展示月工作量、时间报价和换算器。
法定工作日允许按需联网更新并离线缓存（2026-09-07 用户修订，已覆盖原 PRD）。发薪日可自定义 1～31 号。
不做登录、自建服务器、个人数据同步、考勤、社交、后台服务。隐私数据仅存本机，关闭系统云备份。公开时间、日期、节假日和调休数据可联网获取并缓存，当前时刻以系统时钟为准。
开发顺序：脚手架与 domain/测试 → 存储及设置 → 首页 → 心愿 → 退休 → 统计 → 体验。
