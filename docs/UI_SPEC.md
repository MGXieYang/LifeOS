# 界面规范
浅灰米白背景、森林绿主色、浅青柠强调。大号等宽金额、圆角卡片、克制 Emoji，首页优先展示收入/下班/进度。
首页金额按系统整秒计算，工作状态显示轻微呼吸效果；午休和下班停止动态状态。所有页面可滚动，适配键盘、系统导航栏和大字体。
首次引导：欢迎 → 月薪 → 自定义上班、午休开始、午休结束和下班时间 → 发薪 → 可跳过退休信息 → 首页。
设置表单允许随时修改四个工作时间点，提供明确的 HH:mm 格式、顺序验证和错误提示；保存成功后立即重算首页及统计。心愿有空状态、编辑、实现/取消实现、删除确认及三种排序；操作失败不丢失编辑内容。
退休年月是政策结果，具体日是估算；未来工作日显示预计。缺失年度提示应在涉及金额换算的各页可见。
