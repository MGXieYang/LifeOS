# LifeOS V3.0 界面规范

底部固定四项：当下、天平、时间、设置。界面现代、轻松、干净、有数据感，使用森林绿、浅青柠、圆角卡片和克制 Emoji；支持跟随系统、浅色和深色主题；主题点击后立即切换并持久化。界面动画固定启用，不展示动画或文案模式开关。页面可滚动并适配系统栏和输入法。

## Onboarding

统一显示 LifeOS，不将“牛马驱动器”作为 App 名。三步为欢迎、必要工作设置、可跳过个人信息。默认 09:30—19:00，午休 12:30—14:00，发薪日 7 号。

## 当下

首屏层级固定为今日牛马 Hero Card、本月已赚、距离发薪。Hero 金额最大，包含状态、已工作、倒计时、进度；工作中金额按系统时间实时变化。首页固定使用轻松文案，不提供文案模式开关。首页不放退休、节点、Decision、生活换算或自由时间。

## 天平

顶部输入可选商品名和金额，Slider 实时改变金额。中央必须是可辨认的天平：左侧金额/商品，右侧工作代价砝码，横梁与砝码随压力动画。其下依次显示压力结论、工作小时、工作日、月薪比例；不得输出买/不买。长期使用默认折叠；提供只清空当前输入的重置按钮。历史由右上入口进入独立页面，记录不会自动删除，只提供逐条手动删除。只算不保存是默认行为。

## 时间

顶部年度进度环，随后是年度自然日/工作日/非工作日/法定假期余额；人生时间轴展示当前、未来 40/50 岁节点和退休；自定义节点展示年月日、自然日与自然周末；新增节点通过按钮进入独立页面，时间首页不内嵌新增表单；退休卡显示政策结果与估算说明；未来预算用 90/180/365 天切换。

## 设置

分组为工作、个人、显示、数据、日历、关于。工作设置保存后立即重算；出生日期和退休类别必须同时填写或一起留空；显示只提供主题选择，动画固定启用。Phase 1-5 不暴露不兼容的 V2 JSON 备份入口。
