# V3 天平规则

天平回答“这个东西对我来说到底重不重”，不是购物清单，也不替用户决定是否购买。

基础输入为金额和可选商品名。LifeBalanceCalculator 用当前月薪和有效工时换算工作小时、工作日与月工资比例，PurchaseWeightPolicy 统一产生很轻、偏轻、适中、偏重、很重五级结果。Slider 与天平动画只负责交互和视觉，Float 仅用于绘制，金额计算保持 BigDecimal。

长期使用是默认关闭的可选输入：使用月数、每天/每周/每月频率与次数。UsageValueCalculator 输出预计次数、单次成本、每天成本和每月成本；总结来自固定规则，不联网、不使用 AI。

用户可只算不保存。主动保存时 Room 只记录 name、price、usage 配置与 createdAt；没有考虑中/已购入/已放弃、分类、置顶、附加成本、持有成本、资产、预算、投资回报或机会成本。
