# 退休政策
版本 CN-2025.1，2025-01-01 生效。
依据 https://legalinfo.moj.gov.cn/pub/sfbzhfx/zhfxfzzx/fzzxyw/202409/t20240913_506025.html
附表核对 https://www.guide.gov.cn/zwgk/fdzdgknr/flfg/gjfg/content_400014140
男性原 60 岁、女性原 55 岁：原退休月份自 2025-01 起，每四个出生月增加一个退休月，最多 36 个月。女性原 50 岁每两个月增加一个月，最多 60 个月。
设 m 为原退休年月距 2025-01 的月差。m<0 不延迟，否则 delay=min(floor(m/step)+1, cap)。生日直接加总年龄月数，月末自动截断，避免闰年先加年再加月丢失日号。
官方对照表精确到年月；日级倒计时采用该月对应生日（无该日取月末），UI 明确标注日期估算。退休当日及之后显示已达法定退休年龄，剩余为零。
未来工作日始终为预计：已知年使用日历，其余按普通周。此模块只计算一般人员法定年龄，不判定养老金资格、缴费年限、特殊工种或弹性提前/延迟退休。
政策变更时替换 RetirementPolicy/Calculator，增加三类边界与官方表格回归测试，更新版本与本文件；禁止在 UI/ViewModel 中编码政策。
