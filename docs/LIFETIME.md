# V3 人生时间规则

时间页只展示自动变化、无需每日维护、具有长期感知价值的数据，不承担时间管理。

年度模块显示进度、剩余自然日、工作日、非工作日和显式法定假期。人生时间轴基于出生日期，展示当前年龄、尚未到达的 40/50 岁节点与退休；出生信息缺失时给出设置提示。

自定义节点支持年龄或日期。详情显示到目标的年月日、自然日和完整自然周末；自然周末仅按星期六+星期日统计。节点不包含 Todo 或完成状态。

退休沿用渐进式延迟退休策略，显示预计退休日期、年月日、自然日、预计剩余工作日和政策版本，具体日期与未来工作日明确标记估算。

未来时间预算从明天起计算 90/180/365 天，显示工作日、非工作日、显式法定假日和完整可休周末。完整可休周末要求星期六、星期日都不是法定工作日；跨入未收录年份时提示估算。

时间页不包含睡眠、通勤、必要生活时间、工作日自由时间、自由时间比例、工作占用比例、自由夜晚或时间换算器。
